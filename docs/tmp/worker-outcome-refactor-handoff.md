## The design in short

One fact ("how the run ended") currently fans out by hand into four projections across six exit branches of `src/worker/library-processing-runner.ts`: job row status, account event, measurement row, library-processing change. Replace with:

- `src/lib/workflows/library-processing/worker-outcome.ts`: a `WorkerOutcome` discriminated union (enrichment: completed / blocked / failed; match_snapshot_refresh: published / superseded / failed) and pure exhaustive projections `finalStatusOf`, `accountEventsOf`, `measurementOf`, `changeOf`, plus `workerOutcomeFromMeasurement(row)` as a Zod decoder that also accepts the legacy rows the runner writes today (outcome `blocked` included). `counts` on enrichment outcomes come from the run result, not from `job.progress`.
- `src/worker/finalize.ts`: `finalizeJob(job, outcome)` runs **one** transaction: fence `status='running' AND attempts=<claim>` → job row terminal → measurement insert → account events. Returns `applied | lease_lost`. After any errored attempt, re-read the row and treat it as applied when the row carries this claim's status, attempts and error text (same idea as `retryTransition` in `src/lib/platform/jobs/lifecycle.ts`). The raw `postgres()` pool moves here from `settlement.ts`; `src/lib` must never import `src/worker`.
- Runner: `recordWorkerOutcome(ctx, outcome)` = finalize with retry derived from `finalStatusOf` (completed: 3 retries, stop with `finalize_failed` on exhaustion; failed: single attempt, log, continue) → `applyLibraryProcessingChange(changeOf(outcome))`. `RunContext = { job, actor, workflow }` replaces the threaded parameters. Lease loss is `lease_lost`; "superseded" keeps only the newer-request meaning.
- Recovery (`terminal-recovery.ts`): decode the latest measurement with `workerOutcomeFromMeasurement`, apply `changeOf`. Conservative failure remains only when no measurement exists.
- Remove the direct `match_snapshot_refresh_settled_at` write from the finalize transaction once recovery decodes reliably. The reconciler is the only writer of freshness.
